# 0Library (Obsidian)

볼트 전용 플러그인: 편집 모드 표에서 열/행 크기, 선택 셀 병합, 병합 해제 등.

## 수동 설치

1. 이 저장소를 `Vault/.obsidian/plugins/0library/` 에 클론하거나 압축 해제합니다.
2. 폴더에 `main.js`, `manifest.json`, `styles.css` 가 있어야 합니다.
3. Obsidian 설정 → 커뮤니티 플러그인에서 0Library를 켭니다.

## 개발

빌드 단계 없이 `main.js` 가 엔트리입니다.

## 라이선스

저장소 소유자 기준으로 정합니다 (미기재 시 별도 추가).
